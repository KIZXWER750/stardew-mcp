# Stardew MCP 1.8.0 — 피에르 영업 확인·수확물 판매·상자 꺼내기

1.7.0 기반입니다. 자동 물 보충과 농사, 씨앗 구매, F6 입력/F7 취소를 유지합니다.

추가 기능:

- 거래 시간 09:00~17:00, 수요일 휴무와 회관·마을 열쇠 예외, 축제 달력 확인.
- 인벤토리 수확물 조회 → 실제 피에르 상점에서 정상 판매 → 돈·물품 증감 검증.
- 주변 일반 상자 찾기 → 정상 개방 → 수확물 조회 → 한 스택 꺼내기 → 인벤토리 검증.
- 보존 수량과 최저 판매금액, 같은 목표 내 동일 스택 반복 처리 방지.

상점의 실제 메뉴가 최종 거래 근거입니다. 건물 입장 가능 시간과 거래 가능 시간을 구분하며 휴무에는 강제 입장·메뉴 생성·시간 변경을 하지 않습니다. 판매 대상은 채소·과일·꽃 수확물이며 씨앗·도구·자원·퀘스트/특수 아이템은 제외합니다. 한 스택 전체 단위로만 처리하므로 일부 수량을 남겨야 하는 스택은 건너뜁니다. 자세한 함수 계약은 FUNCTIONS.md에 있습니다.

## 설치

게임/SMAPI 종료 후 ZIP을 C:\Users\dlwns\Desktop\test에 압축 해제합니다.

```powershell
& "C:\Users\dlwns\Desktop\test\stardew-mcp-v1.8.0-shop-selling\Install.ps1" -GamePath "E:\SteamLibrary\steamapps\common\Stardew Valley"
```

Go 1.24 이상, .NET SDK, 게임/SMAPI, 로그인된 Copilot CLI가 필요합니다. Go 테스트와 C# 게임 참조 빌드 성공 후 기존 모드를 백업·교체합니다. -BuildOnly는 설치하지 않고 빌드만 합니다. Windows 서버 exe와 소스를 포함하며 게임 DLL은 포함하지 않습니다.

## 사용 및 제한

세이브를 불러오고 F6에 자연어 요청을 입력합니다. 좌표는 AI가 관측하여 선택합니다. 판매·상자 꺼내기를 허용할지, 남길 작물·수량, 구매 예산을 명시하세요. 테스트용 프롬프트는 전달 답변에 제공합니다. TESTING.md는 없습니다.

상자는 기본 일반 플레이어 상자만 지원합니다. 냉장고·출하함·주니모/특수 상자 등은 제외합니다. 꺼내기에는 인벤토리 빈칸이 필요합니다. 상자/상점 메뉴를 열어 둔 상태에서는 F6 창을 새로 열 수 없으므로 먼저 닫으세요. 작업 중 Shift/Ctrl은 놓아두세요.

부분 거래가 실패하면 이미 바뀐 물품·돈을 되돌리지 않습니다. 받은 금액과 남은 물품을 보고하며 자동 재시도하지 않습니다. 커서에 물품이 남으면 인벤토리에 직접 넣어 정리하세요. F7 취소는 이미 끝난 거래를 환불하지 않습니다.

이 환경에서는 게임 없이 Go 테스트·Windows 빌드·C#/Go 문법 검사까지만 수행했습니다. **C# 게임 API 타입 검사와 실제 상점/상자 동작은 사용자 게임 PC에서 검증해야 합니다.**
